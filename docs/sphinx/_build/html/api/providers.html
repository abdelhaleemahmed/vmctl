vmctl.providers

Provider backends translate between the provider-neutral VMConfig model and the hypervisor-specific APIs.

Base Provider

Base provider interface for hypervisor backends.

All hypervisor providers (VirtualBox, libvirt, QEMU, etc.) must implement this abstract base class to ensure consistent API across providers.
