Changelog
=========

v1.1.8 (2025)
--------------

* **Fix**: VirtualBox CD-ROM drives backed by ISO images are now correctly
  identified as ``DVD`` type instead of ``HDD``.
* **Feature**: CLI migrated from argparse to Click with full shell tab
  completion for bash, zsh, and fish.  VM names are completed live from
  VirtualBox.
* **Docs**: Added ``docs/features.md``, ``docs/USER_GUIDE.md``, and
  ``docs/index.html`` GitHub Pages landing page.
* **Docs**: Added Sphinx developer documentation (this site).
* **Docstrings**: Added Google-style docstrings to all public classes,
  methods, and enum types.

v1.1.7 and earlier
-------------------

See the `GitHub releases page <https://github.com/ahmedhal/vmctl/releases>`_
for earlier history.
